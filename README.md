# Inspiratoria — demo

Maqueta responsive de Inspiratoria en HTML, CSS y JavaScript, sin dependencias.

Demo: https://simplementehh.github.io/Inspiratoria/

## Desarrollo

Con Node.js, ejecutar `node build.cjs` para regenerar las páginas y `node server.cjs` para ver el sitio en http://localhost:4173.

La landing se edita en `home-template.cjs`; las secciones de equipo y clientes en `team-template.cjs` y `trust-template.cjs`. Los contenidos se encuentran en `content.js` y `landing-content.js`.

## Publicación

GitHub Pages sirve los archivos de la rama `main`, desde la raíz. Las rutas relativas funcionan bajo `/Inspiratoria/`.

## Alcance de la demo

Los formularios preparan borradores de correo; no envían ni almacenan datos. Hay contenidos pendientes de confirmar, identificados en pantalla: retrato de Macarena, relatores y detalles de proyectos. Los logos de Walmart Chile y Saesa cargan desde sus sitios oficiales. Las imágenes locales de marca y collage provienen del sitio de Inspiratoria. No se incluyen fotos generadas ni testimonios inventados.
